# Legal Tabular Review System

A full-stack system for extracting, comparing and reviewing legal documents in tabular format.

## Features

- **Document Ingestion**: Support for PDF, DOCX, HTML, TXT formats
- **Field Extraction**: Field extraction with citations and confidence scores
- **Side-by-Side Comparison**: Tabular view for comparing multiple documents
- **Export**: CSV export with all metadata

## Tech Stack

**Backend:**
- FastAPI (Python 3.11+)

**Frontend:**
- Next.js 16
- Tailwind CSS
